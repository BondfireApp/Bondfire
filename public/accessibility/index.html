ACCESSIBILITY

Coordination software has to be usable by the people doing the coordinating.

Bondfire’s interface work includes keyboard access, visible focus treatment, semantic structure, responsive layouts, reduced-motion handling, and status communication that does not rely on color alone.

CURRENT PRACTICES

  • Semantic headings and labeled navigation on public trust pages.
  • Visible keyboard focus states.
  • Responsive layouts designed for narrow screens and touch input.
  • Reduced-motion preferences respected on new public surfaces.
  • Canary and security status text does not rely on green/red color alone.
  • Long technical strings are allowed to wrap instead of forcing horizontal overflow.

Bondfire does not claim external WCAG certification. Accessibility is treated as ongoing product work rather than a badge purchased from the compliance-industrial complex.

REPORT A PROBLEM

Accessibility problems can be reported through the project’s existing repository/support channels. Include the affected page, browser/device, what you expected, and what blocked you. Do not include private organization data in a public report.
